### Shutdown device

**Request**

Shuts down the device.

| Method | Request URI           |
| :----- | :-------------------- |
| POST   | /api/control/shutdown |

**URI parameters**

- None

**Request headers**

- None

**Request body**

- None

**Response**

- None

**Status code**

| HTTP status code | Description               |
| :--------------- | :------------------------ |
| 200              | Shutdown request accepted |
| 4XX              | Error codes               |
| 5XX              | Error codes               |

**Available device families**

* Windows Mobile
* Windows Desktop
* Xbox
* HoloLens
* IoT
