### Restart device

**Request**

Restarts the device.

| Method | Request URI          |
| :----- | :------------------- |
| POST   | /api/control/restart |

**URI parameters**

- None

**Request headers**

- None

**Request body**

- None

**Response**

- None

**Status code**

| HTTP status code | Description              |
| :--------------- | :----------------------- |
| 200              | Restart request accepted |
| 4XX              | Error codes              |
| 5XX              | Error codes              |

**Available device families**

* Windows Mobile
* Windows Desktop
* Xbox
* HoloLens
* IoT
