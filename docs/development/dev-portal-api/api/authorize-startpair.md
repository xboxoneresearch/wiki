### Start device pairing

**Request**

Starts pairing mode to display a PIN on the device screen.

| Method | Request URI              |
| :----- | :----------------------- |
| POST   | /api/authorize/startpair |

**URI parameters**

- None

**Request headers**

- None

**Request body**

- None

**Response**

- None

**Status code**

| HTTP status code | Description       |
| :--------------- | :---------------- |
| 200              | Pairing initiated |
| 5XX              | Error codes       |

**Available device families**

* Windows Mobile
* Windows Desktop
* Xbox
* HoloLens
* IoT
