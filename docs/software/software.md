# Software

Microsoft ships *thousands* of individual programs, libraries, and drivers.
This section aims to document some of them.

## Types

| Type   | Info                                                     |
|--------|----------------------------------------------------------|
| `.exe` | Executable. Might be a console tool, service, game, etc. |
| `.dll` | Dynamic Link Library. Used by other software.            |
| `.sys` | Drivers, acts as an intermediate between 2 layers.       |

## SystemOS
